安全提示

  • 使用 Fine-grained PAT 而非传统 Token，权限可细化到指定仓库。
  • 仅授权目标仓库 Repository access 选择 Only select repositories，并选中 Fintinger/hugo-auto-deploy。
  • 仅授予 Contents: Read and write 不需要 Issues / Pull Requests / Actions / Admin 等其他权限。
  • 设置过期时间 建议 90 天或更短，过期后重新生成。
  • Token 永不入库 本 Admin 仅在浏览器 sessionStorage 保存，不会写回 GitHub 仓库。

GitHub Token 创建： github.com/settings/tokens
