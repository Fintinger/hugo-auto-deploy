# 博客首页改版 · 三套设计方向

> 2026-10 设计稿，尺寸 1820×880（与用户截图同尺寸）。
> 目的：解决首页「复古 / 不够现代 / 有些机械」的观感，同时保留现有的插画视频素材。
> 说明：文章标题、日期、分类数量均为占位内容，用于验证信息密度与排版，不代表真实数据。
>
> **状态（2026-10-28，P1 内容页）**：首页保持紫色一屏 + 遮罩搜索；内容页 P1 已落地——深色玻璃 chrome、左侧 rail、文章列表 / 归档 / 分类标签页、文章阅读面板基础版。实现见 `impl-home-*`、`impl-search-overlay.png`、`impl-posts-1820.png`、`impl-archives-1820.png`、`impl-categories-1820.png`、`impl-article-1820.png`。

## 现状诊断

**为什么显得复古**

- 全屏插画视频 + 毛玻璃卡片，是 2020 年前后「壁纸 + 玻璃拟态」的典型组合；插画本身是 lo-fi / 雨天小屋的怀旧叙事。
- 首页深色电影感，文章页却是 PaperMod 默认亮色，站点没有统一的视觉语言。
- 字体是系统默认，颜色没有从插画中提取，圆角、阴影、按钮尺寸各自为政。

**为什么显得机械**

- 所有元素沿中轴对称、等距排列、权重相同：头像 → 名字 → 8 个图标 → 2 个等大胶囊按钮，像工具栏 / 系统弹窗。
- 导航、卡片、页脚不在同一套栅格里；导航浮在插画上，对比度随背景变化。
- 首页只有「名片」，没有最新文章、分类、时间线等「还在写」的证据，容易像模板占位。
- 动效使用 animate.css 的 bounce / slideInDown；卡片默认近乎透明、hover 才显示，第一眼看不到内容。

## 三套方向

### V1 · 影院编辑（cinematic editorial）

`v1-cinematic.png`

- 插画降为「氛围层」：左侧压暗渐变 + 底部渐隐，右侧保留画面细节。
- 大字号 ARCHAI + 一句定位 + 两行简介 + 主次两个 CTA。
- 底部增加「最近更新」列表，让首页有内容。
- 导航收进同一条基线，搜索做成胶囊 + ⌘K 提示。
- 右下角「LANZHOU · 19:24 · 小雨」是可选的动态状态行。
- **适合**：舍不得满屏氛围、想低风险快速升级。
- **代价**：本质仍是深色海报；文章页亮色需要另外统一。

### V2 · Bento 信息面板

`v2-bento.png`

- 背景虚化压暗，前景 5 张玻璃卡片：个人卡片 / 最近更新 / 分类与标签 / 归档 / 找到我。
- 个人卡片补充「33 篇文章 / 5 个分类 / 2021 开始写」的元信息。
- 社交链接从图标工具栏改成文字胶囊；归档用细条形图表达年份密度。
- **适合**：希望首页承担导航与内容分发，信息效率优先。
- **代价**：最像「后台面板」，个性最弱；插画被虚化后损失较大。

### V3 · 纸上画廊（gallery / editorial）

`v3-gallery.png`

- 暖纸色底 + 深墨字，插画变成右侧一幅圆角「作品」；视频仍然播放，只是被框住。
- 左侧是大字号字标、宋体中文副题、简介、主 CTA、文字社交链接与最近更新。
- 从插画提取暖橙 `#C96337` 作为唯一强调色；朱砂色小方块呼应画面里的灯。
- **适合**：想一次性摆脱复古、并让首页与亮色文章页统一。
- **代价**：变化最大；插画从「环境」变成「作品」，需要接受亮色首页。

## 落地约束（如选其中一套）

1. **不改 `themes/PaperMod/`**：新增项目级 `layouts/partials/index_profile.html`（Hugo 优先使用项目级模板）与 `assets/scss/common/custom.scss`（项目级资源会覆盖主题同名文件）。
2. 首页继续走 `profileMode`，在 `config.yml` 的 `profileMode` 下扩展 `homeLayout`、`latestCount` 等开关，保留回滚能力。
3. 「最近更新」用 `site.RegularPages` 取前 3 篇；不改 `_default/list.html`，避免影响 `/posts/` 列表页。
4. 视频加 `poster="/images/poster1.webp"`、`preload="metadata"`；移动端用 poster 或静态图，`prefers-reduced-motion` 时暂停。
5. 移动端需要单独排版：V1 文字压在上、插画在上半屏；V3 框景改为顶部横幅，正文下移；V2 卡片单列。
6. 验证：`.\hugo.exe` 构建、1820×880 与 390×844 两档截图、导航对比度、视频加载体积；V1 若保留深色首页，需要决定文章页是否同步深色。
7. 社交链接目前 8 个（含 QQ / 微信二维码），建议压缩为 4–5 个主要入口 + 「更多」，避免工具栏感。

## 追加：V1 + Extra 的两种排法（2026-10-27）

用户选定 V1 之后，把 `Extra` 页（`/extra`，数据在 `static/data/lists.json`，6 个真实项目）纳入首页，出了两版。以下两版已切到紫色终版；V2 / V3 仍保留暖橙备选。

### A · 首屏项目架

`v1a-extra-shelf.png`

- 首屏底部改为三栏：最近更新 / Extra 项目索引 / 精选项目（ACMUSIC）。
- 一屏内能看到 4 个项目名 + 1 个精选项目，其余通过「全部 6 个」进 Extra。
- 代价：底部增加约 300px 暗色带，插画下半部分（地板、键盘、桌边）被压暗；首屏信息密度明显变高。

### B · 首屏 + 下滑项目墙（推荐）

`v1b-extra-hero.png`（首屏）+ `v1b-extra-wall.png`（下滑后的项目区）

- 首屏保留 V1 的构图：新增 `Extra` 导航项、`看项目 ↓` 副 CTA、底部 `SCROLL · 06 PROJECTS` 提示。
- 下滑后是完整 6 个项目墙：2×3 横向卡片，真实截图、描述、`Live Demo` / `GitHub`。
- 需要允许首页滚动（当前 `style.js` 会锁滚动），并把锚点 `#extra` 接到项目区。
- 首屏不动，项目作为「第二幕」；首页承担精选墙，`/extra` 继续承担完整列表，分工清楚。

### 数据与实现

- 首页项目卡片可以直接从 `site.Data.lists.lists` 渲染（Hugo 0.83 支持 `site.Data`），按 `pinned` 排序，避免和 `/extra` 的 `lists.json` 维护两份。
- 缩略图统一 256×162：普通图 `object-fit: cover`；竖图（京东）用 `object-fit: contain`，否则会裁掉狗和 logo。
- A 的精选卡取 `pinned: true` 的项目；B 的墙取全部 6 个。
- 移动端：B 的项目墙改单列；A 的三栏改单列、精选卡置顶。
- 若选 B，需要放开首页的 `overflow:hidden`，并考虑滚动后导航变 sticky 玻璃条；视频在 `prefers-reduced-motion` 时暂停。

### 其他页面适配（方案）

- **内容页 chrome**：首页只有品牌 + 搜索；内容页桌面用「返回首页 + 面包屑 + 搜索」的窄条，左侧固定一条 文章 / 归档 / 分类 / 关于 的竖向 rail（或保留顶部 5 项导航作为过渡），移动端用抽屉。
- **文章列表**：玻璃索引页；左侧粘性筛选（分类/标签/年份），右侧沿用首页的日期 + 标题行；分页；内容页可滚动，不强行一屏。
- **文章详情**：近不透明的阅读面板（max-width ~760），不在正文下直接透背景；左侧目录；代码块、表格、图片、脚注统一；紫色只做链接/当前目录；阅读页不套 bento 卡片。
- **归档**：把首页归档卡展开成纵向时间线，年份 + 数量 + 紫色节点；与归档页共用数据。
- **分类/标签**：玻璃 taxonomy 页；chips + 数量 + 过滤后的文章列表；和首页分类卡同一套 chips。
- **About**：复用 hero 卡片（头像、XIAN、统计、社交），下面是时间线/生活片段；不重复首页的一屏限制。
- **Extra**：Vue 单页保留自身结构，只换 token（玻璃 header、紫色强调、项目卡 hover）；加「返回首页」和站点搜索入口。
